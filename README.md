# DSH AU05

## 跨设备、跨应用与跨平台解耦

当前增量重构分离设备能力、原生平台服务与 DSH 应用适配边界，保留现有 AU05 操作、授权和撤销规则；不表示已经支持 macOS、其他设备或其他 Agent。现有插件 ID、配置和包名不变。当前接线、尚未通用化部分与后续接入要求见[可扩展架构](<docs/extensible-architecture.md>)。

## 通用钩子：DSH Hooks（独立插件）

不需要 AU05 / Studio、只想管理本地自动化？使用新包 `@abworks/dsh-hooks`。提供事件分组设置页、命令编辑、全局/单项开关和有限运行记录，详见 [DSH Hooks 文档](https://github.com/abworks-dev/dsh-hooks)。它借鉴 Codex Hooks，不是完整兼容实现；旧 `@abworks/dsh-studio-hook` 保留为硬件桥，不破坏已有配置。

## 当前源码新增：叭哥说单击切换与只读采集灯联动（单轮实体闭环通过）

在 Windows 本机 Direct 模式选择“应用预设 → 网易叭哥说”，开启语音与灯光反馈；K1 录音灯现默认启用，不再提供独立实验开关，重连无需另行开启。新的 K1 按下只轻点一次 RightAlt，松开不操作、长按不重复；只有精确绑定的叭哥说进程实际采集时才请求 K1 呼吸，不用按键次数推算状态。观察器只读 CoreAudio 会话状态、不采集音频；应用重启、状态过期或异常不会自动重绑／补按。内置 DSH 长按语音与其他键灯保持原行为。窗口失焦时 K1 灯与按键仍受当前会话护栏限制；浮窗抢焦点需在叭哥说内停止或切回 DSH 输入框，断开插件不会停止外部采集。

**2026-11-03，Windows Direct／叭哥说 1.0.41.0 已由用户确认“K1 单击启动 → 呼吸 → 再按 K1 停止 → 熄灭”，同连接开／关配置独立 GET 一致。** 仅此现场闭环通过，不代表长期稳定、Studio 或应用崩溃根因已解决。本项是打包后新增源码，**旧 dev.3 ZIP 不包含**；完整步骤见[产品指南](<docs/product-guide.md#叭哥说单击切换与采集灯新增源码>)。

125 ms 检测优化版运行时出现观察超时，**现已按用户要求将原生检测恢复为已验证的 250 ms**；原生检测仍为 250 ms；当前输入框聚焦且采集状态有效时，按键投递轮询由 200 ms 缩短为 100 ms，K1 切换后最多 2 秒为 50 ms，其余保持 200 ms。未提交的取消请求由 Host 明确确认后解除对应切换等待；已提交或结果不明仍禁止自动重试。仍须确认真实采集才亮灯，不放宽 2 秒失鲜护栏、不自动重绑或补按。回退后的独立只读 20 秒采样未复现超时，但**尚不能认定历史超时根因已解决，也不是产品重载／实体时延验收**。详见[检测回退与边界](<docs/product-guide.md#采集灯延迟优化后续源码>)。

## 可选跨应用 K1 听写（叭哥说专用，新增源码）

在本机 Windows 桌面的 Direct 模式选择网易叭哥说、启用语音并连接设备后，可勾选默认关闭的“跨应用 K1 听写”。在 QQ 等应用的非密码可编辑输入框新按 K1，发送一次固定 RightAlt 点按；灯光反馈开启时，K1 根据已验证的实际采集状态呼吸，DSH 失焦不再单独关闭该提示。K2、K3、旋钮不放宽后台操作权限。关闭灯光反馈不停止听写，断开插件也不保证停止叭哥说采集。

需要 DSH 客户端和 Host 保持运行；后台节流可能造成按键延迟，超龄手势不会补按。仅叭哥说预设支持此例外，其他语音模式仍受原有焦点限制。当前源码的跨应用链路尚未进行 QQ／浮窗／实体灯验收，旧归档不包含本项。使用步骤与安全边界见[跨应用说明](<docs/product-guide.md#可选跨应用-k1-听写2026-11-04-新增源码尚未实机验收>)；上方原有焦点限制在未开启本选项时继续适用。

## Windows 语音宿主收音观察（新增源码，未做实体验收）

Direct 模式选择 Windows 语音、开启语音与灯光后，Host 自动运行只读 Windows capture session / peak 观察；不使用 Win+H 的发送成功或按键次数推断收音。共享语音宿主实际采集并不保证消费者就是特定听写面板。界面显示真实 0..1 峰值；未确认、失鲜、失败、撤销授权或断开时停止观察并请求 K1 熄灭，不自动重试快捷键。

按最新需求，**不以音量调灯**：确认实际采集时 K1 保持呼吸，不采集时灭。原生观察间隔 250 ms、相同状态去重；峰值仅作界面辅助反馈，不改变任何灯光亮度或模式。其他任务通道保持原向量，实体效果尚未验证；Studio 不启动该观察器。

## 0.6.0-dev.4：适配 DSH 0.2.3 的会话状态注入（新增源码，未实机验收）

DSH 0.2.3 把客户端会话状态拆成独立包 `@deepseek-ai/dsh-client-ui-session-status`，以 `super(ctx, 'uiSession.sessionStatus')` 注册成独立 Cordis 服务。Cordis 的注入守卫按服务名检查（`cannot get property "${prop}" without inject`），只声明 `uiSession` 已经不够，必须把 `uiSession.sessionStatus` 单独写进运行时 `inject`。

受影响表现：插件页红色 `@abworks/dsh-plugin-au05: Error: cannot get property "uiSession.sessionStatus" without inject`，提示条“本页面的插件未能完成同步；服务端的启用状态保持不变。”，AU05 面板与悬浮层整体不出现。此时服务端启用状态没变，点“重试本页面同步”只会重载同一份代码，必然再失败。

本版改动：`packages/dsh-plugin/client.js` 与 `packages/dsh-studio-hook/client.js` 的注入数组加入 `'uiSession.sessionStatus'`，两个包的 `dsh.client.inject` 加入 `@deepseek-ai/dsh-client-ui-session-status`（该字段只影响模块加载顺序，不决定 `apply` 时序）。其余 API 在 0.2.3 已核对未变：`ctx.uiSession.adapter`、`sessions.list`、`sessions.binding()`，以及 `shell.overlay`、`conversation.input.left`、`conversation.input.dock` 三个 slot。**仅完成代码与离线回归，未做新版 GUI／硬件验收。**

## 怎么使用

要求：DSH Host 在 Windows 本机运行；Node.js 22 或 24、PowerShell 7；AU05 USB 接收器与发射器已连接。当前参考运行时为 DSH `0.2.1-rc.3`，不保证其他版本兼容。

1. 在仓库安装声明的 SDK 依赖，不执行依赖安装脚本：

   ```bash
   npm install --ignore-scripts --no-audit --no-fund
   ```

2. 在 DSH 官方插件管理器添加本仓库的 `packages/dsh-plugin` 本地目录，启用插件及其 `au05` 组件。更新已有安装后需重新加载组件和当前 GUI；不启动替代 Web 服务。
3. **先退出 Ulanzi Studio（含托盘）和旧只读采集器。** 接收器被其他程序占用时，连接会失败；插件不会强关其他应用或循环重连。
4. 打开右上角“AU05”胶囊，点击“连接设备”。可选勾选“启动时自动连接设备”：默认关闭，保存后下次插件加载只尝试一次；失败或主动断开后仍需手动连接。不需要额外 HTTP 桥或令牌。
5. 语音可选 **DSH 内置／Windows 原生／应用预设／自定义快捷键**，分别记住启用状态，均默认关闭。应用预设含 Typeless 与网易叭哥说，均使用右 Alt（RightAlt）；改过应用快捷键时选择独立自定义；自定义是独立选项，不藏在预设内。DSH 按住 K1 录音、松开转写；外部语音新按 K1 发出完整点按，松开不操作；结束方式、麦克风和润色等由应用自身管理，不自动发送。
6. “旋钮行为”可选切换会话、上下滚动、整屏滚动或禁用旋转；默认为切换会话，选择会保存。滚动仅限当前主会话自己的已加载内容；旋钮按下仍聚焦输入框。

详细说明见 [0.5 产品指南](<docs/product-guide.md>) 和 [插件说明](<packages/dsh-plugin/README.md>)。

## 按键语义

| 操作 | 当前实现 |
| --- | --- |
| 按键 1 | DSH 按住录音／松开转写；Windows 单按请求系统听写；第三方单按发送预设／自定义快捷键，Typeless 再按结束；不自动发送 |
| 按键 2 | 无待处理交互时发送当前草稿；当前审批可回答时仅允许一次 |
| 按键 3 | 拒绝当前审批，或取消当前运行 |
| 旋钮左 / 右转 | 可选当前工作区会话切换、当前会话上下滚动／整屏滚动或禁用；不跨会话滚动 |
| 按下旋钮 | 聚焦当前会话唯一的输入框；作用域不明确时不执行 |

只处理当前唯一活动会话。窗口失焦、会话/审批/输入绑定变化会让旧按压失效，按住键跨会话不会变成新操作。没有永久放行、全局 Escape、全局键盘监听或任意 HID 包入口。转写发生草稿冲突时保留可恢复文字，不擅自覆盖或发送。

任务灯语义对齐官方 Codex Hooks：**K2 确认呼吸、K3 人工介入／可请求中断呼吸、旋钮任务推进常亮、K1 仅实际 DSH 录音呼吸**。只显示当前唯一主会话，不汇总审批数量；等待审批时不把仍为真的 `running` 冒充任务推进。窗口失焦保留当前任务提示，但不允许后台按键操作。第三方快捷键已发送不代表已知录音状态。**目标状态、系统接受写入、配置回读一致、物理可见灯态是四层证据。** 无法验证原设置快照时不继续改灯；每个目标逐通道提交后独立 GET，明确区分未回读、不一致与一致。Direct 模式连接且启用灯光反馈时持续接管任务灯；无有效任务／录音提示时请求四灯关闭，不恢复原灯效。关闭灯光反馈、断开或正常退出时才尽力恢复首次接管前保存的全局模式与四通道完整记录。亮度只影响接管期，不重写原快照。关闭灯光反馈表示退出任务灯接管、恢复原灯效，不再等同于关闭设备全部灯光。正常释放时尽力恢复原配置，但不保证设备一定响应、异常断电或强制结束后仍能恢复。

## 当前架构

```text
DSH 中文胶囊 / 会话输入槽
    ⇅ DSH 已有连接、认证与公开会话服务
官方 Cordis Host 插件：au05/connect / poll / disconnect / status / windowsVoice / shortcutVoice
    ⇅ 插件拥有的 PowerShell 7 子进程，受限 JSON stdin/stdout
Windows vendor HID collection ⇄ AU05 USB 接收器
```

- 默认仅点击连接才启动原生子进程。用户可保存启动时自动连接偏好，下次插件加载只尝试一次；展开面板不触发连接，失败／断开不重试。自动连接也会进入产品可写模式，不是只读。
- 当前产品路径不监听额外 HTTP 端口，不使用旧观察器令牌，不把 HID 输入送入模拟桥。
- 原生后端只打开通过 VID/PID、caps 和物理接收器身份校验的 vendor collection；不打开通用键盘接口，不读设备序列号或输出原始报告。
- 前端失联由 Host 租期释放设备；正常断开取消 I/O、停止心跳并关闭句柄。没有后台自动重连或开机自启动。
- 语音偏好恢复不打开麦克风或发送快捷键，仍需新的有效 K1 操作。DSH 采音与转写受所选提供商约束；Windows 与第三方模式由外部管理采音。第三方快捷键为受限白名单内的单次按下／松开，不接受命令、脚本、路径或任意键流；普通浏览器不触发 Host 系统快捷键。不能保证断开插件即停止 Windows 或 Typeless 听写。
