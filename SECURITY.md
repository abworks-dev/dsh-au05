# Security policy

This is a design/mock prototype, not a supported production HID or approval bridge. There are no supported binary releases yet. Never run it as administrator or expose the loopback service through a public tunnel.

Do not put tokens, personal session IDs, request keys, keyboard captures, device serials or approval contents in public issues. Use GitHub's private vulnerability reporting if available; otherwise contact the repository owner privately before sharing exploit details. No separate security email address has been established.

See [the threat model](docs/security.md). A public issue may describe non-sensitive design concerns only. This project does not bypass DeepSeek Harness authorization or sandbox controls.
