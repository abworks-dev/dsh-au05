# 可扩展架构：第一阶段

本轮是行为保持的增量解耦，不是新增 macOS、其他设备或其他 Agent 支持。产品名称候选为 VibeInHand；现有包名、RPC、持久化键和插件 ID 不改，以免破坏已有安装。历史架构文档不作为当前接线图。

## 当前边界

```text
DSH UI / composer slots
  → DSH application adapter（目标解析、目标身份比较、审批）
  → client coordinator（手势、新鲜度、焦点、撤销、轮询）
  → existing authenticated DSH RPC
  → Host coordinator（所有权、租期、票据、生命周期）
      → device adapter / profile → Windows AU05 native helper
      → platform services → Windows voice / shortcut / capture / scroll helpers
```

- 应用适配器负责理解宿主公开对象；控制器负责决定旧手势是否仍有资格作用于该目标。两者不能互相替代。
- 设备 profile 仅描述输入事件与反馈向量的能力；不打开硬件、不执行动作、不授予权限。其他设备可以有不同的事件名、通道数或没有反馈通道。
- AU05 的按键、四灯、灯值范围和本机启动描述属于 AU05 适配层，不是所有设备的标准。
- 平台服务负责构建具体原生桥，控制器可以通过依赖注入替换实现。现有独立 bridge 注入保持兼容。
- Direct 与 Studio 仍是两种现有传输路径，不是两种 Agent；不能把传输抽象当作跨应用适配已经完成。
- 浏览器入口仍是构建生成的单文件。应用与语音源模块经构建脚本内联；新增 Host 核心文件必须随插件打包，不依赖仓库之外的相对路径。

## 必须保留的行为

1. 新的连接需要现有明确授权；导入模块和构造适配器不得开始设备 I/O。
2. 所有权、generation、sequence、context、有效期、按住状态和撤销仍由原控制链路维护；不能因适配器支持某个方法就放宽操作。
3. 目标变化、失焦或断连后，不把旧动作重放到新目标；结果不明不自动重试。
4. 审批仍只回答当前可回答对象的一次允许或拒绝；不提供通用永久批准。
5. 已回答去重状态应与反馈共用，避免重复回答或重新亮审批灯。
6. K2 的建议接纳事件仍同步、可取消、限定会话，未接纳才回退到提交草稿。
7. 收音状态与快捷键成功分离；配置读回与物理灯光可见分离。
8. 叭哥说跨应用例外仅适用于已有 K1 路径，不授予 K2/K3/旋钮后台权限。

## 尚未通用化的部分

- 当前产品路由与 UI 仍以 AU05 的 K1/K2/K3/旋钮为主，不是任意设备映射编辑器。
- 客户端 composer/scroll slot 桥仍由 DSH 提供，独立桌面宿主尚未实现。
- 外部听写、采集观察和原生滚动仍为 Windows 实现；macOS 返回不支持，不能用空实现伪装成功。
- 未增加任意脚本、任意 HID 数据包、全局键流或后台审批入口。
- 不引入第三方插件动态加载、插件发现和不受信模块执行机制。代码适配器与用户配置有不同的信任边界。

## 后续接入顺序

### 第二种设备

实现明确的连接/关闭、输入边沿和反馈能力，使用独立 profile；先用无灯设备验证能力降级。现有 AU05 wire 事件不作为跨设备公共协议直接推广。设备原始事件需映射到应用无关的意图后，再交给目标适配器；先为第二种设备验证意图集合，再扩大配置模型。

### 第二个 Agent

优先使用官方插件/API。明确目标身份、状态来源、支持动作和动作结果；监听 Hooks 不代表具有控制或审批能力。没有可靠审批接口时，不支持硬件批准，而不是盲发 Enter。普通软件可仅支持聚焦、滚动和听写，无须虚构会话与模型。

### macOS

分别实现 AU05 HID 后端和平台服务，包括辅助功能权限、前台目标、输入注入、麦克风与状态观察。先达到 AU05 + DSH 的最小闭环，再扩展外部软件。不得仅凭 dsh-app: URL 判断 Windows 或 macOS 原生能力。未提供的能力必须失败关闭。

### 独立宿主

后续如需脱离 DSH，再新增单实例宿主、受认证 IPC、生命周期和安装更新机制；保留 DSH 作为应用适配器。不在当前重构中启动新的服务。

## 验证

运行 `npm run build:plugin`、适配器契约测试、现有 Direct/Studio 客户端与 Host 回归、`npm test`。纯测试使用模拟桥和目标对象，不连接设备或执行真实审批。代码/离线测试通过不代表 GUI 或实体设备验收完成。
